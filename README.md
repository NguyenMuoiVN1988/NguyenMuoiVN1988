# Public Study - Tài liệu học tập công khai

Website học tập được xây dựng với Jekyll và deploy trên GitHub Pages.

## 🌐 Website
**URL:** https://nguyenmuoivn1988.github.io

## 📚 Nội dung
- **Toán 12:** Ôn tập thống kê, Vector trong không gian, Min Max trong Oxyz
- **Toán 9:** Phương trình và hệ phương trình bậc nhất hai ẩn
- **Tiểu học:** Toán tư duy, chuyển động, đếm, hiệu tỷ

## 🚀 Cách chạy locally
```bash
# Cài đặt dependencies
bundle install

# Chạy Jekyll server
bundle exec jekyll serve

# Mở http://localhost:4000
```

## 📝 Cách thêm nội dung mới
1. Tạo file markdown mới trong thư mục tương ứng (T12/, T9/, Tieuhoc/)
2. Thêm link vào index.md
3. Commit và push lên GitHub
4. GitHub Pages sẽ tự động build và deploy

## 🔧 Công nghệ sử dụng
- Jekyll 4.3.0
- GitHub Pages
- MathJax (hỗ trợ công thức toán học)
- Kramdown (Markdown parser)
